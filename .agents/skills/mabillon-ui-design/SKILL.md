# Mabillon UI design

Canonical reference: `docs/architecture/0005-ui-design-language.md` plus the existing application templates/CSS.

Use small radii, neutral surfaces, clear borders, subtle shadows, restrained accent color, semantic forms/tables/filter/pagination patterns and visible keyboard focus. Prefer existing tokens/components. No utility-class soup, external font/CSS CDN or framework dependency without an explicit architecture decision.

Review desktop/narrow viewport, long German labels, empty/error states and full-page/HTMX consistency.
